# Analizador de Logs en Python

Proyecto académico del bootcamp **AI for Devs Jr de Kodigo**. El programa lee un archivo de texto UTF-8, analiza sus líneas y muestra estadísticas de severidad y fechas.

## Requisitos

- Python 3.10 o superior.
- No se requieren dependencias externas.

## Ejecución

Desde esta carpeta, ejecuta:

```text
python analizador_logs.py
```

Después escribe la ruta de un archivo de logs

También puedes probar directamente con los archivos incluidos:

```text
python analizador_logs.py
```

Luego introduce `logs_correctos.txt` o `logs_inconsistentes.txt`.
